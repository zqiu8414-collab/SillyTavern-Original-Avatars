# 原图头像 · Original Avatars

让 SillyTavern 聊天中的角色头像和用户头像使用原始图片，改善大头像布局下放大缩略图造成的模糊。适用于任何主题，也可以搭配「雨后巴黎」。

## 安装

1. 打开 SillyTavern 的**扩展**面板，点击**安装扩展**。
2. 粘贴下面的仓库地址，完成安装。一般选择仅为自己安装即可。
3. 刷新酒馆页面，在扩展面板展开 **原图头像 · Original Avatars**。

```text
https://github.com/zqiu8414-collab/SillyTavern-Original-Avatars
```

这是独立扩展，不是主题 JSON。使用仓库链接安装后，才能通过酒馆的扩展管理拉取更新。

### 从旧版「雨后巴黎 · 原图头像」迁移

如果此前手动安装了主题压缩包中的旧版头像辅助，请先在扩展管理中停用或删除旧版；手动移走旧文件夹时，应将其移出酒馆的扩展目录。刷新页面后，再通过上面的仓库链接安装本版。不要同时启用两份头像辅助。

迁移不会修改主题文件。旧版只随「雨后巴黎」主题启用，本版由自己的开关控制。

## 开关

扩展面板中的 **启用原图头像** 默认开启。

- 开启：当前聊天及之后显示的聊天头像使用原始图片。
- 关闭：立即撤销本扩展的原图替换，恢复头像当前的原生缩略图来源。
- 开关设置随当前酒馆账号保存，刷新页面或重启酒馆后保留。

更换主题不影响此开关。它只改变头像图片来源，不调整头像的位置、尺寸或相框。

## 更新

打开扩展管理，等待更新检查完成。发现新版本后，点击本扩展的更新按钮，再刷新酒馆页面以加载新代码。也可以使用酒馆的**更新全部**或**更新已启用**功能。

扩展声明支持自动更新；是否以及何时自动更新，取决于酒馆版本和相关设置。安装本扩展不会替你修改酒馆的更新选项。

如果更新提示目录不是 Git 仓库，通常是通过下载 ZIP、手动复制文件安装的。移走这份手动安装副本，再使用仓库链接安装。

## 工作方式与限制

- 仅处理聊天消息中原生的角色和用户头像；从当前酒馆的同源地址加载原图。
- 保留头像原本的 `src`，通过 `srcset` 选择原图，兼容原生点击头像查看大图的流程。
- 原图加载失败时撤销本扩展的替换，回到原生缩略图。其他扩展已有的 `srcset` 或 `picture` 图片来源不接管。
- 不上传头像，不读取聊天正文，不调用模型。不需要图床、API 密钥或额外服务。
- 原图通常比缩略图大，会增加图片加载流量和内存占用。原始图片本身分辨率较低时，本扩展不能补出不存在的细节。
- 主题或其他扩展若改写了原生聊天头像结构，可能不在本扩展处理范围内。

## 文件

- `manifest.json`：酒馆扩展信息。
- `index.js`：原图切换、失败回退和开关设置。
- `style.css`：扩展设置面板样式。
- `CHANGELOG.md`：版本记录。

## 测试

使用 Node.js 的内置测试器，在仓库目录运行：

```sh
node --test tests/regression.test.cjs
```

默认使用测试内的原生行为样例。需要核对自己的酒馆版本时，可通过 `ST_PUBLIC_SCRIPT` 指向该安装的 `public/script.js`；例如 PowerShell：

```powershell
$env:ST_PUBLIC_SCRIPT = '你的酒馆目录/public/script.js'
node --test tests/regression.test.cjs
```

测试覆盖开关保存、原图切换、原生头像点击所用地址、失败回退和其他扩展的图片来源保护。它不模拟实际图片网络请求、图片解码或浏览器渲染。
